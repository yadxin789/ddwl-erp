## 3 核销规则（`app/Services/SettlementService.php`）

| 规则 | 实现 |
|---|---|
| 收款只能核销发票、付款只能核销账单 | `allocate()` 按 `payments.direction` 校验，方向不符抛 `InvalidArgumentException` |
| 不能超核销 | 校验①该笔收付款未核销余额 ②单张发票/账单累计核销 ≤ 开票/应付金额 |
| 幂等 | 同一条收付款 + 同一张发票/账单只允许一条明细，重复提交 **跳过不报错**；`paid_amount` 由"已执行收付款的核销明细"**求和重算**，重复 `apply()` 结果不变 |
| 审批中不虚增 | 只有 `payments.status=executed` 的核销才计入 `paid_amount`；`apply()` 对待审批收付款直接返回 |
| 状态回写 | 0 → `unpaid`；部分 → `partial`；满额 → `paid`；`void` / `pending_approval` 的状态不被覆盖 |
| 归属列 | 新建发票/账单写 `owner_id = 当前录入人`（P0-08 数据范围要求；`owner_id` 为空会让单据在受限岗位列表里不可见） |

## 6 未做 / 边界（如实记录）

- **核销冲销/反核销**（红冲、撤销收款）未做：本期只有正向核销；撤销需同步回滚发票状态，留到后续。
- **预付/预收挂账**：收付款金额大于核销金额时，差额只留在收付款单上（无"预收账款"科目化处理），AR 报表不显示未核销余额。
- **三单匹配**：GR 金额按"实收数量 × 采购单价"估算（收货单本身不存单价），未计退货与运费；只列最近 60 张采购单，未做全量分页。
- **价税分离**：发票 `tax_amount` 仍只是展示字段，核销按含税 `amount` 处理，未拆不含税收入与税额。
- **账龄**：仅逾期 / 30 天内 / 30 天后三桶，没有 60/90/180 天标准账龄表。
- 付款的"会计制单"入口仍挂出纳（P1-01 遗留边界，等后续统一调整）。
