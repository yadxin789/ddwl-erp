## 4 接入向导（三步）

| 步骤 | 路由 | 行为 |
|---|---|---|
| ① 选平台 | `GET /ecom/onboarding`（`ecom.onboarding`） | 国内/国外分组卡片，显示所需凭证数量与申请入口；支持名称搜索；入口含"手动添加任意平台" |
| ② 凭证与参数 | `GET /ecom/onboarding/{platformKey}` | 按 `required_credentials` 动态生成输入项；默认仓、同步频率、授权到期日、回调地址、字段映射 JSON |
| ③ 自检并保存 | `POST /ecom/onboarding/{platformKey}` | 先 `verifyCredentials`，失败**返回 200 + 中文可读错误（不 500）**；成功 `updateOrCreate` 落库，`last_check_result=ok` |

自检规则：
- 预置平台：只校验必填凭证是否齐全（不发起真实 API 调用，避免"接了但不能拉单"被误认为已闭环）；缺项提示"缺少必填凭证：X、Y，请到 <申请页> 申请后重新填写"。
- 自定义平台：校验必填 + 对 `api_base_url` 做一次 5 秒超时 GET 探测；非法 URL / 连接失败 / 超时全部转成中文可读消息，**绝不抛 500**；异常同时 `Log::warning`。
- `config/platforms.probe_enabled`（环境变量 `PLATFORM_PROBE_ENABLED`）可关闭真实探测（离线部署/测试用）。

## 5 手动添加任意平台

`GET /ecom/onboarding/custom` + `POST /ecom/onboarding/custom`：名称、平台标识、接口地址、鉴权方式（API Key / OAuth2 / 签名）、API Key/Token、区域、默认仓、同步频率、字段映射 JSON、状态映射 JSON → 存 `platform_key=custom:{标识}`。保存后 `AdapterRegistry::has('custom:xxx')` 为 true，设置页可见、可启停。

## 6 平台设置页

`GET /ecom/instances`（`ecom.instances`）+ `POST /ecom/instances/{id}/toggle`：

| 项 | 规则 |
|---|---|
| 状态 | 未自检 → 待自检；自检失败 → 自检失败；过期 → 授权过期；停用 → 已停用；正常 → 已启用 |
| 授权到期提醒 | `expires_at <= 今天+7` 记为"7 天内到期"，页头显示数量、行内日期标红 |
| 启停 | 停用即 `status=false`，不产生任何同步任务（本期本来也不产生） |
| 默认仓 / 同步频率 | 实例上可改（toggle 接口支持同时传） |
| 最近自检 | 显示时间 + 结果消息（截断 60 字） |

## 10 未做 / 边界

- **不做交易闭环**（D-22 明确定）：不拉订单、不转销售单、不回写发货、无 outbox/重试/死信/对账；`capabilities()` 三个交易能力全部 `false`，页面统一标"待接入"。后续做交易闭环时复用本期的实例配置与适配器，不改向导与设置页。
- **预置平台自检不发起真实 API 调用**：只校验凭证齐全度。真伪 appkey 要等交易闭环立项后才可能验证（现在没有拉单接口可验）。
- **自定义平台只做连通性探测**：HTTP 200 不代表业务可用（页面文案已写明）；失败信息取底层异常前 120 字。
- **授权到期只做提醒**：不改状态、不阻断、不发通知（通知留给后续告警体系）。
- `platform_sku_mappings` 只建表，**没有维护界面**（本期不强制填）。
- 向导没有"编辑已有实例"页：重复接入同一预置平台走 `updateOrCreate` 覆盖凭证；改默认仓/频率目前走设置页启停接口的附带参数，没有独立编辑表单。
- 自定义平台字段映射 JSON 只校验 JSON 语法，不做 schema 校验（映射键写错不会报错）。
- `ecom.platforms`（旧平台账号页）保留原样，与新接入向导并存，后续应合并到设置页。
