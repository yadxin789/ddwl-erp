# 用户说明书：数据查看与导出口径（V1）

> 适用范围：DDWL-ERP V1 全部岗位账号
> 版本日期：2026-11-10

## 1 敏感字段如何显示

系统对敏感字段统一做掩码，列表、详情与操作日志使用同一套规则：

| 字段 | 显示方式 | 示例 |
|---|---|---|
| 客户/供应商/员工联系电话 | 保留前 3 位与后 4 位，中间打码 | `138****0000` |
| 银行账号 | 仅保留后 4 位 | `****1234` |
| 薪资金额（基本/奖金/扣款/实发） | 完全打码，不显示任何金额 | `****` |

- 需要修改联系电话、银行账号时，请进入对应的编辑页；编辑页由有 `edit` 权限的岗位填写真实值，保存后列表仍按上表显示。
- 掩码由系统统一实现（`App\Support\MaskingService`），不是各页面各自截取，避免同一字段在不同页面口径不一致。
- 权限与数据范围仍照常生效：看不到的部门/本人的数据，掩码也不会让其出现。

## 2 导出：V1 不提供

**V1 不提供数据导出（Excel / CSV / 批量打印均不提供）。**

- 如业务确需导出，将作为独立需求评估（P3 之后单独立项），并强制继承现有数据范围与字段脱敏规则，同时记录"谁、何时、导出了多少行"的审计日志。
- 因此 V1 验收不包含"导出范围校验"；任何声称"已支持导出"的说明均不代表本期能力。

## 3 相关权限

| 能做什么 | 需要的权限 |
|---|---|
| 查看物料列表 | `material.list` |
| 业务页面引用物料数据 | `material.read` |
| 查看检验记录/待检任务 | `quality.inspection.view` |
| 查看检验模板 | `quality.template.view` |
| 查看缺陷代码 | `quality.defect.view` |
| 新增/编辑工资条 | `hr.operate` |

> 薪资页面仅对 HR 岗位开放；即便有页面权限，薪资金额也始终以 `****` 展示，不提供"查看明文金额"的开关。
