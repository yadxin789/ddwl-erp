# P3-05 执行记录：AI 助手业务问答接入（2026-11-10）

> 对应计划：`docs/整改完善计划-v1.4.md` §4.4 第 5 项"AI 助手业务问答接入（当前仅通用对话/OCR）"。
> 结论：**已把"占位回复"换成受权限/数据范围约束的 ERP 业务问答**。四类意图、答案带统计口径与跳转链接、会话可继续追问；未命中才回落通用占位文案。**本期不调用外部大模型**（演示环境无 API Key，`ai_providers` 为空），配置入口保留。

## 1 问题与做法

改前 `AiChatController::send()` 每次新建会话并写死一句"【AI服务未配置】已收到您的消息……"，没有任何 ERP 取数，也没有会话历史展示。本轮：

| 项 | 做法 |
|---|---|
| 意图识别 | `BusinessQaService` 关键词/句式匹配四类：销售汇总、库存查询、待我审批、生产工单进度 |
| 取数 | Eloquent/Query Builder 直查业务表，沿用模型已有全局 scope（数据范围 + 租户） |
| 权限 | 每个意图先判模块查看权限（`sales.view` / `inventory.view` / `production.view`），无权限直接拒答且不带数据 |
| 租户安全 | 库存、生产、审批模块尚未纳入租户隔离，**租户账号一律拒答**，防止借问答绕过 P3-04 边界 |
| 答案 | 固定结构：`【标题】` + 数字 + "口径：……"；销售/库存/生产附对应页面链接 |
| 会话 | 支持 `conversation_id` 续聊；聊天页展示最近消息，最近会话可点选；分页参数由 `c` 改为 `p`，避免与"选中会话 c"冲突 |
| 未命中 | 返回"业务问答暂未命中"+ 四个示例，并提示接入外部模型后开放自由对话 |

## 2 意图与取数口径

| 意图 | 触发示例 | 数据源 | 口径 / 边界 |
|---|---|---|---|
| 销售汇总 | 本月销售额多少？上月业绩？ | `sales_orders` | 按 `order_date` 落在今天/本月/上月/今年；金额 `SUM(total_amount)`；**含未确认草稿，不含取消**；按状态给出单数；受销售数据范围约束 |
| 库存查询 | EL000003 还有多少库存？ | `materials` + `inventory_stock` | 先按物料编码（正则取字母开头编码）或名称模糊匹配；按 `status` 汇总全仓数量；"可用"仅 `available`，另给已预留合计 |
| 待我审批 | 我有多少待审批？ | `ApprovalService::pendingForUser` | 复用 P1-01 口径：当前步骤主审人 + 代批人，排除申请人自批；列出前 5 单业务类型/单号/步骤 |
| 生产进度 | 生产工单进度怎么样？ | `production_orders` | `planned/released/in_progress` 未完工工单；计划数、已完工数、完成率；按交期升序列前 5 张 |

## 6 边界 / 未做

- **没有真实 LLM 调用**：`ai_providers` 无配置，`providerStore` 仅保存配置；`send()` 不读 `api_key`、不发 HTTP，通用问题仍回落占位文案。后续接入需做 provider 适配器 + 无 key 降级。
- **只有四类意图、纯关键词匹配**：换说法（如"营收""卖了多少"部分覆盖）可能不命中；没有语义模型、没有槽位抽取（客户/物料多值、时间自定义区间均不支持）。
- **不保留多轮上下文**：消息都落库并展示，但每次回答只依据当前一句问题，不做上文指代消解。
- **销售口径粗**：含草稿、不扣退货、不拆价税、不算毛利，也不按客户/销售员分组。
- **库存口径粗**：全仓汇总，不区分仓库/批次/库龄，不判安全库存（系统无该字段），不扣在途。
- **生产只看数量**：不判断延期、不读 APS 排程、不看齐套。
- **租户账号只能问销售**：库存/生产/审批模块未做租户隔离，问答已主动拒答；完整开放依赖 P3-04 扩表。
- **回答无引用快照**：未把查询结果 JSON 存库（`ai_messages` 无 meta 列），只存文本；事后审计只能看答案文本。
- **无 Token/费用计量**：`token_usage` 仍为空。
