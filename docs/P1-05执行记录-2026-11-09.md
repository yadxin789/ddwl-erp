## 1 一句话结论

研发从"立项、派任务、传图档"扩到 **立项→设计→试产→量产** 四段阶段门：没有审核通过的基线图档不能进试产；有待审批变更单不能进量产；变更单（ECR）由研发经理审批，批准后才生成新 BOM 版本（旧版本 `superseded`）；"我的任务"能开始/提交/通过，延期批准后任务顺延且逾期标记复位。

## 3 阶段门规则（`RndProjectService::setStage`）

| 规则 | 行为 |
|---|---|
| 只允许逐级前进 | 立项→设计→试产→量产，跳级抛 `DomainException`（"必须逐级推进"）；回退直接拒绝 |
| 试产闸门 | 项目必须有 **1 个 `is_baseline=true` 且 `audit_status=approved`** 的图档，否则抛"无基线图档不得进试产" |
| 量产闸门 | 不得存在 `status=pending` 的 ECR，否则抛"还有待审批的变更单" |
| 留痕 | `stage_changed_at` 落时间，`Log::info('研发阶段推进')` |

## 4 基线图档（`setBaseline` / 审核自动基线）

| 规则 | 行为 |
|---|---|
| 只有审核通过才能设基线 | `audit_status != approved` → 拒绝 |
| 同项目只 1 个基线 | 旧基线 `is_baseline=false` 且写 `superseded_by=新文档id` |
| 自动基线 | 图档审核通过时，若项目还没有基线，自动把这一版设为基线（首个通过版即基线） |
| 页面 | 项目详情图档行显示"基线 / 已被替代"徽标 + 审核通过后可"设为基线"（创建人/研发经理） |

## 5 简版 ECR/ECO（`createEcr` / `approveEcr`）

| 规则 | 行为 |
|---|---|
| 提变更单 | 项目创建人/研发经理填：受影响 BOM、变更类型（BOM 结构/替代料/工艺）、标题、原因；生成 `ECR-YYYYMMDD-###` |
| 审批 | 走 P1-01：`ecr.change` → 研发经理单审（`ApprovalFlowSeeder` 新增 `flow_ecr_change`，流总数 6→7） |
| 批准后才改 BOM | `approveEcr()` 复制原 BOM 全部行生成 `V(n+1)`，`bom_code` 加 `-V2` 后缀（`bom_code` 全库唯一），旧版本 `status=superseded`；变更单写 `new_bom_id` |
| 幂等 | 已批准且已有 `new_bom_id` 的重复回调直接返回，不重复建版本 |
| 页面 | 项目详情新增"工程变更单（ECR/ECO）"卡片：表单 + 列表（申请人、状态、批准后的新版本 BOM） |

## 6 我的任务：开始/提交/通过（`startTask` / `submitTask` / `decideTask`）

| 动作 | 允许角色 | 状态流转 |
|---|---|---|
| 开始 | 执行人（创建人/研发经理兜底） | pending/overdue/rejected → in_progress，清 `is_overdue` |
| 提交 | 执行人 | → submitted；**没有任何交付物直接拒绝**（"尚未上传任何交付物"） |
| 通过/驳回 | 审核人、项目创建人、研发经理 | submitted/in_progress → approved / rejected；重算项目进度，全通过自动关项目 |

路由 6 条（均在 `rnd.create` 权限组内，授权在 Policy 层）：`rnd.projects.stage`、`rnd.documents.baseline`、`rnd.ecr.store`、`rnd.tasks.start`、`rnd.tasks.submit`、`rnd.tasks.decide`。任务动作**不用路由模型绑定**（任务表有"执行人=本人"行级范围，经理会先 404），统一 `withoutGlobalScopes()->findOrFail()` + Policy 授权。

## 9 未做 / 边界

- **ECR 只做 BOM 版本复制**：不含替代料替换明细、成本影响测算、影响在途工单清单（计划已注明 P1-05 只做简版，完整表单体系留后续）。
- **阶段门没有审批**：阶段推进是创建人/研发经理操作即生效（只做闸门校验 + 留痕），未挂审批流。
- **基线只到"图档"粒度**：不校验"必需交付物类型是否齐全"（如必须有原理图+PCB+结构图各一份），只要求至少 1 个通过版。
- 项目详情页 ECR 下拉只列**最近 50 个 BOM**，未按项目产品过滤。
- 任务"提交"允许无审核人（`auditor_id` 为空时由创建人/经理审）；未做"提交后自动锁定执行人再上传"。
- 阶段与项目 `status` 两套状态并存（status 仍管 in_progress/completed），未合并成单一状态机。
