# 基础数据归口管理 v1.0

> 2026-11-10　适用范围：DDWL-ERP 全部基础数据（业务字典与主数据）
> 总原则：**每一类基础数据只对应一个归口部门；归口部门定标准，管理员统一维护，条件成熟后按数据域逐类下放编辑权。**

## 1. 为什么这样定

1. 研发任务类型会被项目模板、历史项目、历史任务共同引用，口径必须跨部门统一，不能由各业务部门各建一套。
2. 基础数据量小、变更频率低，集中由管理员操作成本最低，也便于审计。
3. 归口部门对“叫什么、怎么分类、什么算必选”负责，管理员对“系统里怎么改、改完是否断链”负责，职责分开。
4. 后续要下放编辑权时，按数据域逐个开放，不做“一刀切万能 CRUD”。

## 2. 归口台账

台账落库在 `master_data_domains`，后台入口：**后台管理 → 基础数据管理**（权限 `admin.masterdata.manage`，仅系统管理员）。
归口部门可在台账页直接调整；“维护入口”为空表示该类后台维护页尚未建设。

## 3. 变更与删除规则

1. **改名可以，改口径要归口部门确认**：管理员在后台执行，变更后自动被项目创建页、模板页引用。
2. **删除改停用**：被项目任务或项目模板引用的字典项禁止删除，只能停用；停用后不出现在新建项目/新建模板的可选列表，历史项目与历史任务保持原值。
3. **删除仅限零引用**：后台删除按钮只在“任务引用 0、模板引用 0”时出现；服务端仍二次校验，防止绕过页面直接调接口。
4. **稳定编码**：研发任务类型使用 `RND-TT-NNN` 稳定编码，改名不影响编码；重复执行 seeder 按编码识别，不会覆盖后台改过的名称。
5. **权限按域拆细**：本批只开 `admin.masterdata.manage` 给系统管理员。后续下放时按域新增权限（如 `admin.task-type.manage`），不把现有权限扩大成万能 CRUD。

## 4. 本批已落地

### 4.1 第一批：归口台账 + 研发任务类型

- `master_data_domains` 归口台账表 + 17 条初始清单。
- `rnd_task_types` 增加 `code`（稳定编码，唯一）与 `status`（启用/停用）。
- 后台页面：
  - `/admin/master-data` 归口台账，可改归口部门与启停。
  - `/admin/master-data/task-types` 研发任务类型新增、改名、改执行部门、必选、排序、启停、删除（带引用校验与引用数展示）。
- 研发侧 `/rnd/task-types` 改为只读字典页，不再提供新增入口；原 `POST /rnd/task-types` 已移除，避免出现第二个写入口。
- 新建研发项目、新建模板只加载启用中的任务类型；停用类型不再出现在可选列表。

### 4.2 第二批：四类待建字典补齐

- **计量单位** `/admin/master-data/units`
  - 新增、改名、改编码、改换算系数、启停、删除；已被物料使用的单位（按 `materials.unit` 匹配单位编码或名称）删除被拒，只能停用。
- **税率与结算方式** `/admin/master-data/tax-terms`
  - 税目：新增、改名、改类型、启停、删除；税目下仍有税率时删除被拒。
  - 税率：选税目、税率名称、税率百分比、启停、删除。
  - 结算方式：`payment_terms` 新表（编码唯一、名称、账期天数、说明、启停），新增/编辑/删除。
  - 已预置 3 个税目、5 条税率、5 种结算方式（预付/货到付款/月结30-60-90）。
- **审批流程** `/admin/master-data/approval-flows`
  - 列表 + 新增/编辑页，支持流程编码、名称、业务类型、启停与多节点审批链（节点名称、权限、审批人、代批人）。
  - 安全的服务端约束：
    - 有 `pending` 审批实例的流程禁止改节点，防止在途单据审批链断裂。
    - 已有任意审批实例的流程禁止删除，只能停用。
    - 审批人不得与本节点代批人重复；节点按顺序重新编号。
  - `ApprovalFlowSeeder` 改为 `firstOrCreate`，重复执行不会覆盖后台调整过的审批人。
- **单据编号规则** `/admin/master-data/number-sequences`
  - 支持改前缀、日期格式、流水位数、当前流水、说明、启停。
  - 被 `NumberGenerator` / `MaterialCodeGenerator` 按 `rule_code` 直接调用，**不提供删除**，只能停用；停用后对应业务生成编号会抛出明确异常，提示到本页检查。
  - `current_seq` 可由管理员直接调整，用于补号或重置。
- 台账页顶部新增 4 个维护入口按钮；`MasterDataDomainSeeder` 对已登记的数据域只补空的 `route_name`，不覆盖后台调整过的归口部门。

## 6. 验收口径

- 系统管理员可打开归口台账、任务类型、计量单位、税率与结算方式、审批流程、单据编号规则页面；业务岗位访问返回 403。
- 任务类型可新增、改名、停用、删除；被引用时删除被拒并提示引用数量。
- 停用的任务类型不出现在新建项目/新建模板页面。
- 计量单位被物料引用时删除被拒；税目下仍有税率时删除被拒。
- 审批流程有 pending 实例时改节点被拒；有实例时删除被拒。
- 单据编号规则停用后，对应业务生成编号抛出明确异常；校验规则编码只允许启用状态参与生成。
- `php artisan test` 全绿；`php artisan erp:guard:check` M1~M7 通过。
